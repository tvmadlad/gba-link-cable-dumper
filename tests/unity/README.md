# Unity

[Unity](https://github.com/ThrowTheSwitch/Unity) v2.7.0, the C unit test framework the host tests use. These are `src/unity.c`, `src/unity.h`, `src/unity_internals.h` and `LICENSE.txt` from that release, unchanged. Unity is MIT licensed, see [LICENSE.txt](LICENSE.txt).

To update it, copy the same files from a newer release. `make format` leaves this folder alone.
